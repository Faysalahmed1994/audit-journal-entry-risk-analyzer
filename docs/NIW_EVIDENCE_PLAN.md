# Research and EB-2 NIW evidence plan

**Proposed relationship to the endeavor:** AuditJE is a locally deployable, explainable journal-entry screening and workpaper preparation prototype designed to help auditors evaluate journal-entry risks and document audit evidence in government and nonprofit engagements. A public, reusable implementation can demonstrate initiative, technical expertise, and potential to broaden access to audit analytics.

**Evidence categories worth building over time**
- Product: original source code, release history, methodology, tests, screenshots using synthetic examples, deployment instructions.
- Validation: independent user feedback with written permission, controlled time-and-accuracy benchmarks, external technical review, and comparisons with spreadsheet-only workflow.
- Dissemination: reproducible open technical paper, conference talks, tutorials, non-confidential demonstrations.
- Impact: verifiable third-party adoption, forks, documented use cases, and evidence of broader use beyond one employer — **only if these actually occur**.

**Important:** this repository is supporting project evidence, *not itself an EB-2 NIW petition*, legal opinion, proof of impact, or immigration approval guarantee. Claims must be truthful, substantiated, and reviewed with immigration counsel. Avoid listing proprietary client names, protected workpapers, or confidential firm templates on GitHub.
