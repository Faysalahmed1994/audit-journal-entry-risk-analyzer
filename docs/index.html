Public demonstration, not audit assurance: All displayed journal entries are simulated. This demo makes no network requests to process data, accepts no file uploads, and has no actual client or voucher records. High risk does not establish fraud. AuditJE is under active development and not approved for production audit use.

1. Choose a sampling approach

Change the selections below. The 36-entry dataset is fixed and entirely synthetic; sample IDs update immediately.

The highest-risk entries are selected first; remaining slots use a seeded pseudorandom selection. This is a teaching example, not a statistical sampling methodology.

How the scores work

Indicators include unbalanced entries, weekend/after-hours activity, round or large values, manual sources, year-end proximity, missing preparer, pending approval, and duplicate-line indicators.

Current rule weights are documented in the audit methodology. Scores are heuristic and require independent validation.

Want to test a real audit export?

Use the separately downloadable local AuditJE application only with permission and after reviewing its limitations. Never put client data into public GitHub issues.
